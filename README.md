# Nexa — Analytics Dashboard

A modern, responsive SaaS analytics dashboard built as a frontend portfolio project by **Chetna Patel**, B.E. Computer Science student.

## ✨ Features

- Responsive dashboard layout
- Interactive revenue line chart
- Traffic-source doughnut chart
- Revenue, users, orders and conversion statistics
- Recent orders table
- Top customers section
- Popular products section
- Search/filter interaction
- Dark/light mode with LocalStorage persistence
- Mobile sidebar navigation
- Export report interaction
- Clean SaaS-style UI

## 🛠️ Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript
- Chart.js
- Google Fonts

## 📁 Project Structure

```text
nexa-dashboard/
├── index.html
├── style.css
├── script.js
└── README.md
```

## 🚀 Run Locally

No build tools or backend are required.

1. Download or clone the repository.
2. Open `index.html` in a browser.

For the best development experience, open the folder in VS Code and use the **Live Server** extension.
